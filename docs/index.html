Google Search Ranking & Discoverability Capstone

FlyRank Machine Learning Internship

Abstract

This capstone project presents a machine learning framework for identifying content pages that may represent optimization opportunities using historical search intelligence signals. The objective is to develop a transparent decision-support system that helps prioritize content review activities by analyzing historical search performance, engagement indicators, content freshness, and visibility-related metrics. A complete machine learning workflow was implemented including data preparation, feature selection, baseline comparison, supervised regression modeling, evaluation on unseen data, and ranked recommendation generation. Multiple regression approaches were evaluated against baseline methods using MAE, RMSE, and R² metrics. The results showed that the available historical features provided limited predictive power for the selected target variable. Instead of claiming guaranteed future ranking improvements, this project provides a reproducible framework for prioritizing content optimization opportunities while clearly documenting limitations and areas for future improvement.

Research Question

Can historical search performance, content freshness, engagement metrics, and search visibility be combined to identify content pages that should be prioritized for optimization?

Decision Supported

The purpose of this project is to support content optimization decisions by ranking pages according to observed optimization opportunity. The system does not predict guaranteed future performance. Instead, it provides a structured approach for prioritizing limited optimization resources using historical search intelligence signals.

Selected Lane

Refresh / Content Opportunity Scoring

Expected Output

The final output is a ranked list of content pages containing:

  • Optimization opportunity score
  • Recommended action
  • Reason code explaining prioritization

Dataset

The analysis was performed using the anonymized FlyRank Machine Learning Internship dataset. The dataset contains historical search intelligence information designed for content opportunity analysis while protecting private client information.

  • Dataset: content_refresh_anonymized.csv
  • Rows: 30,000
  • Columns: 44
  • Unit of analysis: One content page observation
  • Dataset type: Historical snapshot
  • Public-safe anonymized variables only

Excluded Information

The following information was intentionally excluded:

  • Client identities
  • Domains
  • URLs
  • Private search queries
  • Future outcomes after optimization

The dataset is suitable for decision-support analysis and ranking experiments rather than causal inference.

Methodology

The project follows a supervised machine learning workflow designed to evaluate whether historical search intelligence signals can support content prioritization decisions. The methodology focuses on measuring observed relationships between available features and the selected target variable while preventing data leakage.

Modeling Objective

The objective is to rank content pages according to their observed optimization opportunity. The model does not attempt to guarantee future traffic growth, ranking improvements, or SEO outcomes. Instead, it provides a prioritization framework for identifying pages that may deserve further manual review.

Feature Selection

Only variables available before an optimization decision were included as predictive features. Selected features include:

  • search_volume
  • competition
  • cpc
  • word_count
  • char_count
  • impressions_90d
  • clicks_90d
  • sessions_90d
  • engaged_sessions_90d
  • days_since_last_update
  • ctr
  • avg_position
  • engagement_rate
  • scroll_rate
  • ai_traffic_pct

Target Variable

The supervised learning target is trend_pct, which is treated as a continuous proxy for observed content momentum. The model estimates relative optimization opportunity based on historical patterns. It does not represent guaranteed future performance after content updates.

Baseline Strategy

Before evaluating machine learning models, a simple business baseline was created using manually weighted historical signals. The baseline considered:

  • Search demand
  • Search visibility
  • Content freshness

Machine learning models were compared against this baseline using the same train-test split to ensure a fair evaluation.

Validation Strategy

The dataset was divided into training and testing subsets using an 80/20 split with a fixed random state. Model performance was measured on unseen testing observations. Additional grouped validation performed during the internship showed that grouped evaluation produced more realistic performance estimates compared with random splitting.

Leakage Prevention

To reduce the risk of data leakage, only information available before an optimization decision was used. Future outcomes, post-update information, and manually created labels were excluded from the predictive feature set.

Results and Model Evaluation

Four approaches were compared:

  • Business Baseline
  • Dummy Regressor
  • Linear Regression
  • Random Forest Regressor

Performance was evaluated using:

  • Mean Absolute Error (MAE)
  • Root Mean Squared Error (RMSE)
  • R² Score

The evaluation measures predictive performance on unseen data. It should not be interpreted as evidence of causal improvement after content optimization.

Interpretation of Findings

The results indicate that historical search performance signals alone provide limited predictive information for estimating content momentum. Search engine performance depends on many additional factors including:

  • Search intent alignment
  • Content quality
  • Technical SEO factors
  • Competitor changes
  • Algorithm updates
  • External authority signals

These factors were not fully available within the anonymized dataset. Therefore, the developed framework should be considered a decision-support system rather than a forecasting engine.

Actual vs Predicted Analysis

A diagnostic scatter plot was generated to compare actual target values against model predictions. The visualization showed predictions concentrated around average values, supporting the quantitative evaluation that the available features contained limited predictive signal for the selected target.

Ranked Recommendations

The final stage of the project generated ranked content opportunity recommendations. Each recommendation contains:

  • Predicted opportunity score
  • Recommended action
  • Reason code

The ranking system is intended to help prioritize manual content reviews. It should not be interpreted as a guaranteed prediction of future Google ranking improvements.

Recommendation Actions

Priority Action Purpose
High Refresh Immediately Pages showing stronger optimization opportunity signals
Medium Review Pages requiring additional SEO analysis
Low Monitor Pages with limited immediate evidence

Limitations

This project provides a structured ranking framework, but several limitations must be considered.

  • The dataset represents a historical snapshot rather than a complete timeline.
  • External ranking factors such as backlinks, algorithm changes, and competitor activity were not fully available.
  • The model measures observed relationships rather than causal effects.
  • Missing values were handled using median imputation.
  • The recommendations should support human decision-making rather than replace SEO expertise.

Future Work

Future improvements could include richer temporal datasets, semantic content embeddings, backlink signals, topical authority features, and advanced ranking models. Potential future approaches include:

  • XGBoost
  • LightGBM
  • CatBoost
  • Large Language Model based content analysis
  • Time-series validation strategies

These improvements may provide additional context and improve the ability to identify valuable content optimization opportunities.
