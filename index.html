Research Question

Can historical search performance, content freshness, engagement metrics, and search visibility be combined to identify content pages that should be prioritized for optimization?

Decision Supported

This project develops a decision-support system that ranks webpages according to observed optimization opportunity. The model helps prioritize limited SEO resources using historical search intelligence signals rather than predicting guaranteed future rankings.

Selected Lane

Refresh / Content Opportunity Scoring

Dataset

  • Dataset: content_refresh_anonymized.csv
  • 30,000 rows
  • 44 columns
  • Unit of analysis: One content page
  • Historical search performance snapshot

Sensitive information such as client identities, URLs, domains, private queries, and future outcomes was excluded from the analysis.

Methodology

  • Data Cleaning
  • Feature Engineering
  • Baseline Opportunity Score
  • Linear Regression
  • Random Forest Regressor
  • Dummy Regressor
  • 80/20 Train-Test Split
  • Leakage Prevention

Selected Features

  • Search Volume
  • Competition
  • CPC
  • Word Count
  • Character Count
  • Impressions (90 Days)
  • Clicks (90 Days)
  • Sessions (90 Days)
  • CTR
  • Average Position
  • Engagement Rate
  • Scroll Rate
  • Days Since Last Update
  • AI Traffic Percentage

Results

Three regression models were evaluated using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R² Score.

The evaluation showed that none of the tested machine learning models outperformed the Dummy Regressor on the held-out test data. This indicates that the available historical search signals provide limited predictive power for the selected target variable.

Although predictive performance was limited, the framework successfully provides a structured decision-support system for ranking content optimization opportunities.

Ranked Recommendations

Limitations

  • Decision-support system only
  • Does not prove causality
  • Historical snapshot dataset
  • External ranking factors not included
  • Google algorithm updates not modeled
  • Seasonality not fully represented
