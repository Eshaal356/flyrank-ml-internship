Google Search Ranking & Discoverability Capstone

FlyRank Machine Learning Internship

Abstract

This capstone project investigates how historical search performance and content quality signals can be used to identify webpages that should be prioritized for optimization. A machine learning workflow was developed to rank content opportunities and support SEO decision-making using structured search performance data.

Research Question

Can historical search performance metrics be used to identify webpages that are most likely to benefit from content refresh and optimization?

Decision Supported

The project provides a decision-support system that helps prioritize webpages for content refresh based on historical SEO signals instead of relying solely on manual review.

Model Evaluation

Multiple regression models were evaluated and compared against a Dummy Regressor baseline using standard regression evaluation metrics. The analysis demonstrated that the selected machine learning models did not outperform the baseline on the held-out test set, highlighting the limitations of the available historical search signals for this prediction task.

Results

Although predictive performance was limited, the developed workflow successfully provides a reproducible framework for ranking webpages according to their estimated optimization opportunity. The resulting recommendations can assist SEO teams in prioritizing content updates.

Ranked Recommendations

Priority Recommendation
1 Refresh Existing Content
2 Improve Content Quality
3 Review SEO Metadata
4 Optimize Internal Linking
5 Monitor Future Performance

Limitations

  • Historical snapshot data only.
  • External ranking factors were not included.
  • Results are decision-support recommendations rather than causal conclusions.
  • Future Google algorithm updates are not modeled.
