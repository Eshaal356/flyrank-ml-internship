Abstract

This capstone project investigates how historical search performance and content quality signals can be used to identify webpages that should be prioritized for optimization. A machine learning workflow was developed to rank content opportunities and support SEO decision-making using structured search performance data.

Research Question

Can historical search performance metrics be used to identify webpages that are most likely to benefit from content refresh and optimization?

Decision Supported

The project provides a decision-support system that helps prioritize webpages for content refresh based on historical SEO signals instead of relying solely on manual review.

Model Evaluation

Three regression models were evaluated using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R² Score.

Model MAE RMSE R²
Dummy Regressor 64.1583 315.9668 -0.0001
Linear Regression 65.8695 317.0327 -0.0068
Random Forest Regressor 71.7958 351.5542 -0.2380

Best Model: Dummy Regressor

Results

The Dummy Regressor achieved the best overall performance with the lowest Mean Absolute Error (64.1583), the lowest Root Mean Squared Error (315.9668), and the highest R² score (-0.0001). Neither Linear Regression nor Random Forest Regressor outperformed the baseline model, indicating that the available historical search signals contained limited predictive information for this prediction task.

Although predictive accuracy was limited, the developed workflow successfully produced ranked content opportunity scores that can support SEO teams in prioritizing pages for review and optimization.

Interpretation

The evaluation suggests that the available search performance features were insufficient to accurately predict future content opportunity scores. The Dummy Regressor performed better than the trained machine learning models, indicating that additional features, richer datasets, or alternative modeling approaches may be required to improve predictive performance.

Visualizations

The notebook includes an Actual vs Predicted Values scatter plot comparing predicted and observed values. This visualization shows that the trained regression models did not significantly outperform the Dummy Regressor baseline, highlighting the limited predictive capability of the available features.

Limitations

  • Historical snapshot data only.
  • External ranking factors were not included.
  • Results are intended as decision-support recommendations rather than causal conclusions.
  • Future Google algorithm updates are not modeled.
  • The evaluated machine learning models did not outperform the Dummy Regressor baseline on the held-out test set.
